# Phase 11 — SEO and Performance

## Objective

Optimize the application for production performance and search engines.

---

## SEO

Implement:

* metadata
* canonical URLs
* sitemap
* robots.txt
* Open Graph
* structured data
* product schema where appropriate

---

## Performance

Analyze:

* frontend bundle
* server rendering
* database queries
* API latency
* images
* caching

---

## Frontend

Use:

* optimized images
* lazy loading
* code splitting
* Server Components where appropriate

---

## Backend

Analyze slow queries.

Add indexes where justified.

Avoid N+1 queries.

---

## Tests

Run production builds.
